# Research Economics Dashboard

Static dashboard for the book *The Economics of Jobs*.

- Live page: https://manjunadhgude.github.io/research-dashboard/
- Research notebook: https://app.notion.com/p/41641ff4c274815ea192d40fb62a858c

Charts are explanatory and must distinguish measured data from conceptual frameworks. Update chart data only from verified research and retain source, population, period, denominator, method and limitations alongside every statistic.
